# Tic-Tac-Toe (Morpion) for Casio Calculator

A fully functional and interactive version of the classic Tic-Tac-Toe game, specifically optimized to run smoothly on Casio graphic calculators using Python (`casioplot`).

## 🎯 Objective
The goal is simple: be the first player to align three of your symbols (either Squares or Crosses) horizontally, vertically, or diagonally on a 3x3 grid. If all cells fill up without an alignment, the game ends in a draw.

## 🕹️ Controls
- **Arrow Keys**: Move the cursor across the grid.
- **EXE / OK Key**: Confirm and place your symbol.

## 🎮 Game Features
- **Interactive Grid**: Precise cursor-based movement from cell to cell.
- **2-Player Mode**: Automatic turn-based alternation between Squares and Crosses.
- **Smart Victory Detection**: Automatic checking of rows, columns, and diagonals to declare a winner or a draw.
- **End-Game Menu**: Clean UI options to instantly replay or exit safely.
- **High Performance**: Optimized rendering algorithms to eliminate screen lag and display bugs.

## 💻 Installation
1. Copy the source code into a `.py` file.
2. Transfer it to your compatible Casio graph math+ calculator or other if it's possible.
3. Run the program and enjoy the game!
